## Project overview

Hexo 8.1.2 static blog (Chinese-language, author: Frank Wang) using the Fluid theme. Deploys to GitHub Pages at `https://ffrankwang.github.io/`.

## Commands

```bash
# Install dependencies
npm install

# Start dev server (default http://localhost:4000)
npx hexo server

# Generate static files into public/
npx hexo generate

# Deploy to GitHub Pages
npx hexo deploy

# Create a new post (scaffold: scaffolds/post.md)
npx hexo new post "post-title"

# Create a new draft
npx hexo new draft "draft-title"

# Create a new page
npx hexo new page "page-name"

# Clean generated files and cache
npx hexo clean

# Regenerate gallery thumbnails and page (after adding photos)
npm run gallery

# Admin panel at /pro/ when dev server is running (hexo-pro plugin)
```

## Architecture

Standard Hexo project layout:
- **`source/_posts/`** — All blog posts (Markdown with YAML frontmatter: `title`, `date`, `tags`, `categories`)
- **`source/about/`**, **`source/resume/`**, etc. — Static pages
- **`source/gallery/`** — Gallery page (auto-generated by `npm run gallery`)
- **`source/img/`** — Images and assets referenced in posts
- **`source/img/gallery/photos/`** — Original photos for gallery (gitignored)
- **`source/img/gallery/thumb/`** — Auto-generated 500px thumbnails (gitignored)
- **`source/img/gallery/display/`** — Auto-generated 1920px display images (gitignored)
- **`source/css/custom.css`** — Custom CSS loaded on all pages
- **`scripts/generate-gallery.js`** — Gallery generation script
- **`scaffolds/`** — Templates for `hexo new` (post, draft, page)
- **`themes/`** — Installed themes (Fluid is the active theme)

## Configuration

Two config files control the site:

1. **`_config.yml`** — Hexo core config (site metadata, URL, deploy settings). **Contains secrets — do not commit changes that add tokens or passwords.** Use environment variables or a separate uncommitted file for credentials.

2. **`_config.fluid.yml`** (987 lines) — Fluid theme config: dark mode, code highlighting, navbar menu, favicon, custom CSS/JS paths, comment system, analytics, etc. The gallery nav item is configured here under `menu`.

## Gallery

The gallery page (`/gallery/`) uses lightGallery.js for a photo grid with lightbox viewer. It appears in the navbar between "归档" and "分类".

### Workflow

1. User drops photos into `source/img/gallery/photos/`
2. Run `npm run gallery` — this script:
   - Generates 500px thumbnails in `thumb/`
   - Generates 1920px display images in `display/` (for lightbox viewing)
   - Writes `source/gallery.json` (photo list)
   - Generates `source/gallery/index.md` with inline photo data
3. `npx hexo generate` — builds the static gallery page
4. `npx hexo deploy` — publishes to GitHub Pages

### To update the gallery

When the user says "更新相册", run `npm run gallery` then regenerate and deploy.

## Post frontmatter

```yaml
---
title: post-title
date: 2016-02-10 08:26:03
tags: tag1
categories: 技术
---
```

Categories and tags are supported. `post_asset_folder: true` means each post can have an associated asset directory.

## Plugins to be aware of

- **hexo-renderer-marked** — Markdown rendering
- **hexo-renderer-ejs** / **hexo-renderer-stylus** — EJS templates and Stylus CSS preprocessing
- **hexo-pro** — Admin panel at `/pro/`; first-time setup prompts to create admin account
- **hexo-deployer-git** — Git-based deployment to GitHub Pages
- **sharp** — Image processing for gallery thumbnails
